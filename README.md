# Dattatray Dudhamogre | Portfolio

Personal portfolio website showcasing my work as a **Java Full Stack Developer** and Technical Trainer.

![Portfolio Preview](https://via.placeholder.com/800x400?text=Portfolio+Screenshot)

## Features

- Modern responsive design with dark/light mode toggle
- Hero section with typewriter animation
- About, Skills, Experience Timeline, Projects, and Contact sections
- Filterable project cards
- Contact form powered by EmailJS
- Smooth scrolling and animations

## Tech Stack

- React 19
- Bootstrap 5
- Custom CSS with CSS Variables
- react-type-animation
- @emailjs/browser

## Getting Started

```bash
git clone https://github.com/Datta2002/portfolio-dattatray.git
cd portfolio-dattatray
npm install
npm start
```

## Deployment

To deploy to GitHub Pages:

```bash
npm run build
npx gh-pages -d build
```
